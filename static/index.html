    Не подключён

    Аккаунт подключён: …

    1. Установите браузер Kiwi Browser (Android)
    2. В Kiwi установите расширение Cookie-Editor
    3. Откройте этот сайт парсера в Kiwi (не в Chrome)
    4. Войдите на m.avito.ru в Kiwi
    5. Cookie-Editor → Export → JSON
    6. Вернитесь на парсер и вставьте JSON ниже
    1. В Safari (не в иконке PWA) откройте m.avito.ru и войдите в аккаунт
    2. Экспортируйте cookies расширением Cookie-Editor для Safari или с компьютера (Chrome → Export)
    3. Нужны cookies sessid и auth — без них вход не сохранится
    4. Откройте PWA «Сигнал» и вставьте JSON ниже → «Сохранить cookies»
    5. PWA и Safari не делят cookies Avito — вставка JSON обязательна
